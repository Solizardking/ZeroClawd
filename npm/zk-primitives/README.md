# @clawd/zk-primitives

Zero-knowledge primitive catalog for **The Clawd Bot**.

```bash
curl -fsSL https://cheshireterminal.ai/clawdbot | bash
npm i @clawd/zk-primitives
clawdbot catalog zk
```

This package publishes the public operation list and install pointers. The
TypeScript SDK is `@clawd/zk-client`. The agent wrapper is `@clawd/zk-shark-agent`.
The on-chain program lives at `zk-primitives/programs/clawd-zk` in
[clawdbot-go](https://github.com/Solizardking/clawdbot-go).
